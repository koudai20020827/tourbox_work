# ショートカット割り当て Prototype

会社端末でも扱いやすい、pywebview製のショートカット割り当てプロトタイプです。UIはスマホ比率の縦長ウィンドウで、入力デバイス風の自前SVGパネルを表示します。

## できること

- ボタンやダイヤル操作にショートカットキーを割り当て
- ダイヤルの左回転/右回転/クリックを別々に割り当て
- UIから割り当てをテスト実行
- テスト実行や入力イベント時にデバイス図の該当部位を発色
- デバイスがキーボード入力として見えている場合、入力をキャプチャして割り当て対象に登録
- 接続確認でmacのUSB/HIDらしきデバイスと `/dev/cu.*` などのポートを表示
- 設定を `config.json` に保存

## セットアップ

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

macOSではショートカット送出やグローバルキー取得に「アクセシビリティ」権限が必要です。初回起動後、システム設定の「プライバシーとセキュリティ」から利用中のターミナル/Pythonに許可を付けてください。

## 入力について

このプロトタイプはまず、デバイスがOS上でキーボード/メディアキーのように見えるケースを想定しています。Raw HIDとしてしか見えない場合は、`app/input_backends.py` の `HidBackend` にデバイスごとのデコード処理を追加する想定です。
