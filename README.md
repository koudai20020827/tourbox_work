# ショートカット割り当て Prototype

会社端末でも扱いやすい、pywebview製のショートカット割り当てプロトタイプです。UIはスマホ比率の縦長ウィンドウで、入力デバイス風の自前SVGパネルを表示します。

## できること

- ボタンやダイヤル操作にショートカットキーを割り当て
- ダイヤルの左回転/右回転/クリックを別々に割り当て
- UIから割り当てをテスト実行
- テスト実行や入力イベント時にデバイス図の該当部位を発色
- TourBox/HID/キーボード入力の信号ログをリアルタイム表示
- 実機信号を画面上の物理ボタンへ学習マッピングして、次回以降その部位を発光
- デバイスがキーボード入力として見えている場合、入力をキャプチャして割り当て対象に登録
- 接続確認でmacのUSB/HIDらしきデバイスと `/dev/cu.*` などのポートを表示
- 設定を `config.json` に保存

## セットアップ

macOSでFinderから使う場合は `Shortcut Mapper.app` をダブルクリックしてください。ログを見ながら起動したい場合は `Shortcut Mapper.command` も使えます。Windowsでは `Start Shortcut Mapper.bat` をダブルクリックしてください。初回だけ `.venv` を作成し、必要なライブラリを入れてからアプリ画面を開きます。

起動しない場合は、同じフォルダに作られる `launch.log` を確認してください。初回セットアップやGUI起動時のエラーが残ります。

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

macOSではショートカット送出やグローバルキー取得に「アクセシビリティ」権限が必要です。初回起動後、システム設定の「プライバシーとセキュリティ」から利用中のターミナル/Pythonに許可を付けてください。

## 入力について

このプロトタイプは、デバイスがOS上でキーボード/メディアキーのように見えるケースと、TourBoxがHIDとして見えるケースの両方を拾います。画面上の物理ボタンを選んでから「実機入力を追加」を押し、TourBox側のボタンを押すと、その生信号が選択中の物理ボタンへマッピングされます。
